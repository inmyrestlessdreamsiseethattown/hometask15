Вариант 16

Условие задачи

Написать программу, которая определяет, какая цифровая клавиша была нажата. Для ввода использовать функцию getch(), объявленную в заголовочном файле conio.h.

Алгоритм

Подключить необходимые заголовочные файлы stdio.h, locale.h и conio.h.

Настроить локаль для вывода сообщений на русском языке.

Вывести приглашение нажать цифровую клавишу.

Считать нажатую клавишу с помощью функции getch().

С помощью оператора switch определить, какая клавиша была нажата.

Если нажата цифра от 0 до 9, вывести сообщение с соответствующей цифрой.

Если нажата другая клавиша, вывести сообщение о том, что клавиша не является цифровой.

Завершить программу.

Блок-схема

    A([Начало]) --> B[Вывести приглашение]
    B --> C[Считать клавишу с помощью getch]
    C --> D{Какая клавиша нажата?}
    D -->|0–9| E[Вывести номер цифры]
    D -->|Другая клавиша| F[Вывести сообщение]
    E --> G([Конец])
    F --> G

Код программы

#define _CRT_SECURE_NO_DEPRECATE
#include <stdio.h>
#include <locale.h>

int main()
{
    setlocale(LC_ALL, "RUS");
    char c;

    printf("Нажмите цифровую клавишу: ");

    scanf("%c", &c);

    switch (c)
    {
    case '0':
        printf("\nНажата клавиша 0\n");
        break;

    case '1':
        printf("\nНажата клавиша 1\n");
        break;

    case '2':
        printf("\nНажата клавиша 2\n");
        break;

    case '3':
        printf("\nНажата клавиша 3\n");
        break;

    case '4':
        printf("\nНажата клавиша 4\n");
        break;

    case '5':
        printf("\nНажата клавиша 5\n");
        break;

    case '6':
        printf("\nНажата клавиша 6\n");
        break;

    case '7':
        printf("\nНажата клавиша 7\n");
        break;

    case '8':
        printf("\nНажата клавиша 8\n");
        break;

    case '9':
        printf("\nНажата клавиша 9\n");
        break;

    default:
        printf("\nНажата не цифровая клавиша\n");
    }

    return 0;
}
